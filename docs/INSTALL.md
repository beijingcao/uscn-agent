# 安装与使用 USCN Agent 41

## 准备

- 一台 macOS 13+ 的 Apple Silicon 或 Intel Mac。
- 可访问 `https://uscn.si` 的网络及你的 USCN 平台账号。
- 如需同步 Codex 服务额度，使用助手支持的 Codex 登录环境。当前交接验证覆盖 Codex CLI 0.160.0 / 0.163.0；其他版本的兼容情况以助手提示为准，不需要为此改动已有客户端配置。

## 安装

从 [v41 Release](https://github.com/beijingcao/uscn-agent/releases/tag/v41) 下载 `uscn-agent.zip`，解压，打开 **USCN Agent 41.app**。可以将应用放到“应用程序”目录，但不需要安装后台系统服务。

如需核对下载完整性，将 `uscn-agent.zip.sha256` 与 ZIP 放在同一目录，在该目录运行：

```sh
shasum -a 256 -c uscn-agent.zip.sha256
```

正常结果为 `uscn-agent.zip: OK`。也可以用支持 SHA256 的图形工具核对。

当前包尚无 Apple Developer ID 签名及公证。若 macOS 提示无法验证开发者，请先核对下载来源和摘要，再使用 macOS 提供的“隐私与安全性”确认入口。不要全局关闭 Gatekeeper；若系统明确提示文件损坏或仍无法打开，请记录 macOS 版本并反馈，不要删除已有 Agent 配置。

## 连接流程

1. 打开应用后，浏览器进入本机助手页面 `http://127.0.0.1:18777/`。
2. 按向导连接 USCN 平台，在平台网页中登录并确认设备归属。
3. 按官方页面完成 ChatGPT 账号选择、工作区和授权同意。官方登录页面由厂商控制；可能需要不止一次确认。
4. 等待模型目录、账号和额度同步。正常连接后，Agent 会持续同步；失败时按页面的重试或恢复提示处理。
5. 按引导进入 [资源与能力](https://uscn.si/#/supply/resources)，查看这次资源的账号与额度信息，设置销售窗口及 100% 可用额度标价，保存并提交审核。
6. 管理员批准销售设置后会自动上架；资源是否可购买与调用仍由实时供给条件决定。

此 GitHub 包预置公网平台入口。已有配置不会因重新下载而被清空；更新时请先在旧助手页面选择“退出 Agent 应用”，再打开新版，以免旧进程占用本机端口。保持原有配对、授权和资源历史，按页面提示完成必要的账号确认。

## 日常使用

- 本机供给时保持 Agent 运行、电脑联网并避免进入休眠。
- 助手通常每分钟同步一次额度，网络和上游响应可能影响实际间隔。
- 额度窗口是 Codex 服务的观测结果，不应推断为所有 ChatGPT 服务的通用余额。
- 平台凭据失效、官网授权失效和额度耗尽是不同状态，按页面相应提示恢复，不需要反复注册账号。
- 若已取消共享，按“重新共享这台设备”的引导重新登记；历史记录保留，不自动继承旧销售批准。
- 退出 Agent 会停止本次本机供给进程；仅关闭浏览器标签页不等于退出应用。

## 反馈问题

提供应用版本、macOS 版本、发生步骤和页面上的支持代码即可。不要提供授权回调链接、密码、Token、API Key、恢复码或私有配置。

安全问题请联系 **uscn.info@gmail.com**，平台使用规则见 [协议与隐私](https://uscn.si/#/terms)。
